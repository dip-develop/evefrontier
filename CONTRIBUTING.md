# Contributing Guide

Welcome to the EVE Frontier open-source project! 🚀  
We appreciate your interest and contributions — whether you're fixing bugs, adding features, improving documentation, or sharing ideas.

## How to Contribute

1. **Create an Issue**  
   Found a bug or want to suggest a feature? Open an issue and provide as much detail as possible.

2. **Fork and Pull Request (PR)**  
   - Fork this repository
   - Create a descriptive branch name: `git checkout -b feature/map-enhancement`
   - Make your changes
   - Open a pull request with a clear explanation of your contribution

3. **Coding Standards**  
   - Format your code with `dart format`
   - Write clean, readable, and well-documented code

4. **Testing**  
   - Add tests for new features or fixes
   - Run all tests with `dart test` before submitting your PR

5. **Continuous Integration**  
   All contributions go through automated CI checks. Make sure your branch passes before requesting a merge.

## Contribution Types

- Bug fixes 🐞  
- New features and packages  
- Performance optimizations  
- UI/UX improvements  
- Documentation updates  
- Discussions and feedback

## Publishing and Releases

Some packages will be published on [pub.dev](https://pub.dev), while others will be released via GitHub downloads. Refer to each package's `README.md` for its release and maintenance strategy.
